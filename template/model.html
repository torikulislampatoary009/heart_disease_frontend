How it works

Telling a sick patient they are healthy (a false negative) is the worst mistake here. So each model has a safety limit set to catch at least {{ ((info.target_recall or 0.95) * 100)|round|int }}% of sick patients in cross-validation. The cost is more false alarms. A patient is flagged if either model reaches its limit.
